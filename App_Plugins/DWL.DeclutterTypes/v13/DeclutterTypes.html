It should be noted that this tool is in Beta, based on our knowledge of umbraco and how to find properties and in use document/data types - if you note a specific type and would like us to investigate, please raise an issue in GitHub

This tool will scan your published content for in use document types and data types. It will also scan your media content for in use data types and properties.

Running this tool will show a list of data types and document types that it has found not in use, but this is not an exhaustive list.

There are still types that may be used and should be verified before you delete them, this tool is a guide and some settings or customised views may still be used but marked as unsed by this tool, so delete with caution.

Once run you will see your unused type below, there is a link to open a new tab to the item the tool has marked.
It is then up to you to verify if this is in use, see if it is logically tied to another that you know to be in use, or Umbraco has found something the tool has not like customised views or settings.

When you have determined that it is safe to delete, you can then remove that document type or data type manually.

The Save In Tool Toggle will allow you to save the results in tool so you do not have to rerun the tool on every visit.
